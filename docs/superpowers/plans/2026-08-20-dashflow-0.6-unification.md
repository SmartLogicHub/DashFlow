# DashFlow 0.6 Unification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship DashFlow 0.6.0 as one coherent, secure, offline-first product with all registered Widgets usable and existing DashFlow configuration upgraded safely.

**Architecture:** Keep the existing native TypeScript/DOM stack. Extract migration, visibility, confirmation, and onboarding decisions into small testable modules; existing services remain adapters to Obsidian APIs. Old `obsidian-dashboard` data is intentionally out of scope.

**Tech Stack:** TypeScript 5.8, Obsidian API 1.11.4, esbuild, Node 22 test runner, vanilla DOM/CSS.

---
