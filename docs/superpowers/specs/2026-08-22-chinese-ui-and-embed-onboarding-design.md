# DashFlow 中文界面与网页嵌入引导设计

## 目标

将 DashFlow 当前主界面中的产品英文统一为自然中文，并让“网页嵌入”卡片在未配置时可以直接进入当前卡片的配置界面。

## 文案原则

- 用户可见的导航、卡片名、指标、状态和操作统一使用中文。
- 保留 `DashFlow` 品牌名，以及 `URL`、`HTTPS`、`HTTP`、`localhost`、`127.0.0.1`、`AI` 等必要技术缩写。
- 内部类型、数据字段和持久化值保持不变，避免迁移风险。
- 旧工作台中由用户保存的自定义卡片标题不强制改写；仅更新插件默认名称和默认文案。

## 界面调整

- `Vault Pulse` 改为“知识库概览”，指标改为“笔记 / 待办 / 项目 / 已完成（或已逾期）”。
- `Magic Embed` 改为“网页嵌入”，`Focus` 改为“专注计时”，`Visual Data Filter` 改为“数据筛选”。
- 主工作台中的 `MY DASHBOARD`、`TODAY`、`NEXT 7 DAYS`、`YEAR END`、Activity 图例等用户文案改为中文。
- 设置说明中用“卡片”代替 `Widget`；周复盘、日历和习惯设置中的普通英文术语改为中文。

## 网页嵌入交互

未配置 URL 时，空状态显示标题、简短说明和“配置嵌入地址”按钮。按钮通过卡片根节点冒泡一个仅在当前 DashFlow 视图内处理的配置请求，`DashboardRenderer` 校验卡片 ID 属于当前工作台后打开原有配置弹窗。

配置完成后仍保留会话级点击加载门槛：远程页面仅允许 HTTPS，本地开发允许 localhost / 127.0.0.1 的 HTTP；iframe 不获得 same-origin 权限。页面加载失败时展示提示，并提供“在浏览器打开”，不绕过目标网站的 CSP / X-Frame-Options。

## 兼容与验证

- 不改变插件数据模型、卡片 type、已有 URL 或布局。
- 自动化测试覆盖中文默认文案、配置事件、URL 安全边界和错误提示。
- 完成单测、TypeScript 类型检查、生产构建和真实 Obsidian UI 烟雾测试。
- 安装产物时保留知识库现有 `data.json`，安装前后校验哈希。
