# 任务概览的主次布局

## 目标

让工作台的「任务概览」优先回答“今天完成得怎样”，同时保留全部任务的进度参照。当前两个同等圆环分散注意力，并在今日没有任务时留下空洞视觉。

## 布局

- 卡片采用左右两栏，在现有工作台尺寸内保持一屏可读。
- 左栏是主指标：`今日`、大号百分比和 `已完成 / 总数`。
- 今日没有任务时，主指标显示 `今天暂无待办`，不渲染无意义的 0% 圆环。
- 右栏是辅助指标：`全部任务`、百分比、`已完成 / 总数` 和一条细进度条。
- 保持为只读摘要；不新增数据、按钮或第二套状态。

## 数据与兼容性

- 继续使用当前 `taskOverview(todayTasks, allTasks)` 的真实数据。
- 将输出明确为主指标（今日）和辅助指标（全部），不改变任务完成计算规则。
- 现有 Dashboard 布局、Widget ID 和 Markdown 数据保持不变。

## 验证

- 单元测试覆盖：有今日任务、今日任务为空、全部任务进度计算。
- UI 源码测试覆盖：仅在有今日任务时渲染主圆环；全部任务使用细进度条。
- 完整测试、类型检查、构建和安装文件哈希校验必须通过。
